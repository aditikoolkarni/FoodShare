# FoodShare – Community Food Donation & Request Platform

## Overview
A platform to connect people for food donations and requests.

## Tech Stack
- Node.js + Express
- MongoDB
- React
- Redis (Queueing & Caching)
- AWS (Deployment)

## Folder Structure
- `backend/` – Server-side logic
- `frontend/` – React frontend

## Getting Started
### Backend
```bash
cd backend
cp .env.example .env
npm install
npm run dev
